# ☕ દૈનિક ચા હિસાબ ડાયરી (Chai Tracker App)

આ એક પૂર્ણ અને આધુનિક **React + Vite** આધારિત ચા હિસાબ ટ્રેકર વેબ એપ્લિકેશન છે, જે તમારી ડેસ્કટોપ ડાયરી (ચોપડો) ની જેમ જ મહિને-મહિને દૈનિક સવાર અને બપોરની ચા નો ઓટોમેટિક હિસાબ રાખે છે.

---

## 🚀 મુખ્ય સુવિધાઓ (Features)

1. **📖 ડાયરી ચોપડા પદ્ધતિ (1 થી 16 અને 17 થી 31)**:
   - જેવી રીતે તમે નોટબુકમાં ૧ થી ૧૬ અને ૧૭ થી ૩૧ દિવસ લખો છો, તેવી જ રીતે ૨-કોલમમાં સરળતાથી એન્ટ્રી કરી શકાય છે.
2. **🌅 સવાર અને ☀️ બપોર માટે અલગ બોક્સ**:
   - દરેક તારીખ સામે સવાર અને બપોરના ચા ના કપ લખી શકાય છે (+ / - બટન અથવા સીધા નંબર ટાઈપ કરીને).
3. **⚡ ઓટોમેટિક માસિક સરવાળો (Auto Calculation)**:
   - **સવારની કુલ ચા (Morning Total)**
   - **બપોરની કુલ ચા (Afternoon Total)**
   - **મહિનાના કુલ કપ (Grand Total Cups)**
   - **કુલ બિલ રકમ (Total Amount ₹ = કુલ કપ × પ્રતિ કપ ભાવ)**
4. **💰 ભાવ બદલવાની સગવડ (Rate Configuration)**:
   - ચા નો ભાવ (દા.ત. ₹10, ₹12, ₹15) સેટિંગ્સમાંથી સરળતાથી બદલી શકાય છે.
5. **💬 WhatsApp રિપોર્ટ શેરિંગ**:
   - એક જ ક્લિકમાં કીટલી વાળા ભાઈ અથવા ઓફિસ મેનેજરને મોકલવા માટે ફોર્મેટ કરેલ ગુજરાતી મેસેજ કોપી થાય છે.
6. **🖨️ પ્રિન્ટ / PDF ડાઉનલોડ**:
   - મહિનાના અંતે બિલની સહી અને સ્ટેમ્પ વાળી પ્રિન્ટ કાઢી શકાય છે.
7. **💾 લોકલ સ્ટોરેજ (Auto-Save)**:
   - પેજ રિફ્રેશ થાય કે બ્રાઉઝર બંધ થાય તો પણ તમારો ડેટા સેવ રહે છે.
